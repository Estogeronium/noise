# ШУМ

Перехваченный эфир вымышленного ведомства: бесконечный поток абсурдной цифровой
пропаганды в глитч-эстетике. Сатира и арт-проект; все организации и «новости» вымышлены.

https://noise.vonzvyagin.ru

## Устройство

Статический сайт без сборки + Cloudflare Worker для LLM.

- `index.html`, `style.css` — оболочка, форма «внедрить сигнал», футер с кредитами
- `main.js` — отрисовка «экрана» на 2D canvas, очередь передач, глитч-события, ввод
- `glitch.js` — WebGL-шейдер: RGB-расщепление, разрывы строк, битые блоки, шум
- `grammar.js` — локальный генератор (запасной режим, работает без сети)
- `config.js` — адрес воркера
- `worker/` — Cloudflare Worker (OpenAI + бюджетные лимиты), деплой в `worker/README.md`

Если воркер недоступен или бюджет исчерпан, эфир продолжает идти на локальном генераторе.

## Локальный запуск

ES-модули не открываются с `file://`, нужен любой статический сервер:

```
python3 -m http.server 8000
```

Текст текущей передачи дублируется в `aria-live` для скринридеров.
